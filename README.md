## 🚀 تنظیم خودکار با ایمیل (ویژگی جدید)

نسخه جدید edgetunnel امکان تنظیم خودکار کانفیگ را با وارد کردن ایمیل فراهم می‌کند!

### 📧 نحوه کار

1. **کاربر به سایت مراجعه می‌کند** 
   - صفحه `/setup` یا ریشه سایت نمایش داده می‌شود

2. **ایمیل خود را وارد می‌کند**
   - ایمیل معتبر مانند `example@gmail.com`

3. **سیستم به صورت خودکار:**
   - ✅ UUID منحصربه‌فرد بر اساس ایمیل تولید می‌کند
   - ✅ کانفیگ کامل در KV ذخیره می‌شود
   - ✅ لینک اشتراک اختصاصی ایجاد می‌کند
   - ✅ لینک مدیریت (ادمین) ارائه می‌دهد

4. **کاربرد کانفیگ**
   - از لینک اشتراک در کلاینت‌های مختلف استفاده کنید
   - از لینک مدیریت برای تنظیمات پیشرفته استفاده کنید

### ⚙️ متغیرهای مورد نیاز

| متغیر | توضیح | مثال |
|-------|-------|------|
| `ADMIN` | **الزامی** - رمز برای تولید UUID و کانفیگ | `MySecurePass123` |
| `HOST` | **الزامی** - دامنه شما | `vless.example.com` |
| `KEY` | اختیاری - کلید اضافی برای امنیت بیشتر | `extra_secret_key` |

### 🎯 مزایای روش جدید

- 🔓 **بدون نیاز به تنظیمات دستی**
- 🔐 **هر کاربر کانفیگ اختصاصی دارد**
- 📱 **سازگار با همه کلاینت‌ها**
- ⚡ **سریع و خودکار**

## 📝 دستورات سریع

### نصب و استقرار

```bash
# 1. کلون کردن پروژه
git clone https://github.com/your-username/edgetunnel-auto.git
cd edgetunnel-auto

# 2. نصب وابستگی‌ها
npm install

# 3. ایجاد KV Namespace
npx wrangler kv:namespace create KV
# ID دریافتی را در wrangler.toml قرار دهید

# 4. استقرار
npm run deploy

# یا با محیط تولید
npm run deploy:prod
